# Building with AI

Class materials, exercises, and a reference you can keep.

---

# Start with a check

Before asking a model to do a task:

- Name the result you want.
- Supply the context it needs.
- Decide how you will check the result.

---

# Ground the answer

Give the model trusted source material.

Ask it to quote the passage that supports its answer, then check the quote yourself.

---

# Try it

Ask one question the source can answer and one it cannot.

Compare the responses. What would you change?
