## Start with evidence

A model can produce a confident answer without enough information. Give it the material it needs, and ask it to distinguish evidence from assumptions.

This lesson is MDX. You can add Astro or React components here when an exercise needs interaction. Plain Markdown is enough for most lessons.

## Exercise: answer from a source

Choose a short document and ask a question it can answer.

```text
Use only the document below to answer my question.
Quote the passage that supports your answer.
If the document does not contain the answer, say so.

Question: ...
Document: ...
```

Check the quoted passage against the original. Does it actually support the answer, or does it just mention the same topic?

## Try a missing detail

Ask a second question whose answer is not in the document. Check whether the model admits the gap. If it invents a detail, record that failure and revise your instructions.

## Discuss

What did the source help with? What still required your judgment?
